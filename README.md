# Device & Dispatcher Gateway

Практична робота №2.

## Опис

Консольний мережевий сервіс диспетчеризації на мові Go.

У межах Рівня 1 реалізовано багатопотоковий TCP-сервер, який приймає підключення клієнтів та обробляє текстові команди.

## Реалізовані команди

- `ECHO <повідомлення>` — повертає повідомлення клієнту.
- `TIME` — повертає поточний час сервера у форматі RFC3339.
- `CLOSE` — закриває з'єднання.
- `QUIT` — закриває з'єднання.
- Невідома команда — повертає повідомлення з переліком доступних команд.

## Технології

- Go 1.22+
- пакет `net`
- TCP
- goroutines
- `bufio`
- `strings`
- `time`
